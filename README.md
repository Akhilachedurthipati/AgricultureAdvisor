# AGRICULTURE ADVISOR 🌾

An AI-Powered Multilingual Agricultural Decision Support Platform.
Major Project for B.Tech in Computer Science and Engineering (Artificial Intelligence and Machine Learning).

---

## 🌟 Overview
**Agriculture Advisor** empowers farmers and agricultural practitioners with real-time, AI-driven advisory tools designed for accessibility across linguistic and digital literacy barriers. It brings modern MERN-stack engineering and intelligent machine learning pipelines directly into an intuitive, nature-inspired user experience.

---

## 🚀 Key Modules
1. **Intelligent Crop Recommendation:** Analyzes environmental and soil parameters (soil type, season, temperature, humidity, pH, rainfall) to recommend the single best-suited crop with cultivation rationale.
2. **Precision Fertilizer Recommendation:** Evaluates N-P-K nutrient status and land area to deliver precise fertilizer advisories with safety protocols.
3. **Crop Disease Detection:** Dual-mode leaf diagnosis (photo upload & live camera capture) identifying leaf pathologies, symptoms, causes, and treatment methods.
4. **Weather Monitoring & Alerts:** Real-time agro-meteorological monitoring with critical event alerts (heavy rain, extreme heat, storm risks).
5. **Multilingual Voice Assistant & AI Farming Chatbot:** Natural language voice-interactive farming assistant supporting voice input (Speech-to-Text) and audio responses (Text-to-Speech) across major Indian languages.
6. **Multilingual Interface:** Full localization across English, Telugu, Hindi, Tamil, Kannada, Malayalam, Marathi, and Bengali.
7. **Farmer Authentication:** Secure JWT-based authentication with bcrypt password hashing and user profiles.
8. **Recommendation History:** Complete historical audit trail of past recommendations and consultations with privacy-preserving controls.

---

## 🛠️ Technology Stack
- **Frontend:** React 18, Vite, Tailwind CSS, Lucide React, Axios, React Router DOM, i18next
- **Backend:** Node.js, Express.js, MongoDB, Mongoose, Zod, JWT, bcryptjs, Multer
- **AI/ML:** Real crop decision pipeline, leaf disease classification, Google Gemini LLM API
- **APIs:** Browser Web Speech Recognition & Synthesis, OpenWeatherMap

## 💻 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm (v9+)
- MongoDB (Local or Atlas URI)

### Setup & Run
1. **Clone and setup Backend:**
   ```bash
   cd server
   npm install
   cp .env.example .env
   npm run dev
   ```
2. **Setup Frontend:**
   ```bash
   cd client
   npm install
   npm run dev
   ```
